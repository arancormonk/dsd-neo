Android NDK r28c C++ runtime in the dsd-neo APK: notices

lib/arm64-v8a/libc++_shared.so is the NDK r28c (28.2.13676358) file
toolchains/llvm/prebuilt/linux-x86_64/sysroot/usr/lib/aarch64-linux-android/libc++_shared.so, stripped of
debug information by the Android Gradle plugin (build ID 7befe631535aa853c4f4ac1293e49dcea34c9b6e). It
contains LLVM's libc++, libc++abi and libunwind and compiler-rt builtins, built from llvm-project
3b5e7c83a6e226d5bd7ed2e9b67449b64812074c with Android's patches (toolchain/llvm_android
e727bfb014bd436f581a66a450c939a6983a1fc3; clang r530567). These are licensed under the Apache License 2.0
with LLVM Exceptions (licenses/Apache-2.0.txt and licenses/LLVM-exception.txt); code contributed before
LLVM's relicensing is also under the legacy terms below. Every native library in the APK also contains
the NDK's startup objects (crtbegin_so.o, crtend_so.o) from Android's bionic, under the BSD notice in
section 5.
